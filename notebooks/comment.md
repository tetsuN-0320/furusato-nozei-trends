# コメント：　修正追加作業の依頼
現場のダッシュボードを以下の方向で改良を検討してください。

## データの解釈
取得できているデータから
- レビューの数　≒ 人気度　と解釈する。
- レビュー評価　≒ 高いほど価格に見合う価値がある、「良い商品」と解釈する。
- この両方がバランスよく高いと、その商品カテゴリ、自治体は「評価が高い」と推測できる、と仮説して分析を行う。
Kmeansクラスターの結果を見ると分析としてあまり面白いものではなかった。
食品コスパ型　と　家電・高額品特化型　にほぼ分かれている。
食品プレミアム型（少数あり）や　最近話題になっている　日用品コスパ型がまだ、このデータからは発見できなかった。

## データの分析項目
新しいものの追加をしてください。
今ある
- カテゴリ別商品件数（既存）
- 価格帯別構成比（既存）*
- 自治体のレビュー数ランキング（既存）*
  		自治体別のランキング表は、「レビュー数」、「評価点」、「受入額（総務省）」で並び替え（昇順及び降順）ができるようにしてください。
- 価格 × レビュー数（カテゴリ別）（既存）*
- レビュー数 x レビュー評価の散布図（新規）*
- 自治体別レビュー数及びレビュー評価の散布図（新規）*
合わせて現在の「絞り込み」機能はあまり意味がないので変更をしてください。
絞り込みは下記の３項目に変更。この絞り込みの対象となるグラフは、上記の*マークをしたもの。
- カテゴリ
- 評価点（1〜5のチェックリスト）
- 自治体タイプ
